# Composables Reference

The `nuxt-gsheet` module provides four auto-imported client-side composables to fetch, transform, and update Google Sheets data.

## useGSheet

The `useGSheet` composable is the base hook. It fetches spreadsheet cells as a raw grid of values (an array of arrays).

### Parameters

*   `range` (string): The range of cells to fetch (e.g. `'Class Data!A1:F10'`).
*   `options` (object): Configurable options like `sheet`, `cacheMaxAge`, or `valueRenderOption`.

### Example

Fetch a raw student grid in your SFC component:

```vue [app.vue]
<script setup lang="ts">
// Fetches cell grid. Returns { data, pending, error, refresh }
const { data: grid, pending, error } = await useGSheet('Class Data!A1:F10')
</script>

<template>
  <div v-if="grid">
    <div v-for="(row, idx) in grid" :key="idx" class="flex gap-2">
      <span v-for="(cell, cellIdx) in row" :key="cellIdx">
        {{ cell }}
      </span>
    </div>
  </div>
</template>
```

## useGSheetAsObject

The `useGSheetAsObject` composable fetches cells and transposes the rows into an array of objects. It treats the first row of the range as column headers.

### Example

Fetch students mapped to headers:

```vue [app.vue]
<script setup lang="ts">
// Automatically maps cell values to header keys
const { data: students } = await useGSheetAsObject('A1:C10', { sheet: 'siswa' })
</script>

<template>
  <ul v-if="students">
    <li v-for="student in students" :key="student.nis">
      {{ student.nama }} - {{ student.kelas }}
    </li>
  </ul>
</template>
```

## useGSheetRow

The `useGSheetRow` composable extracts and returns a single row from a range based on its 0-indexed position.

### Example

Fetch the header row (index `0`) of a spreadsheet:

```vue [app.vue]
<script setup lang="ts">
// Extracts row 0 (headers)
const { data: headers } = await useGSheetRow('Class Data!A1:F10', 0)
</script>

<template>
  <div v-if="headers" class="flex gap-2">
    <span v-for="header in headers" :key="header" class="badge">
      {{ header }}
    </span>
  </div>
</template>
```

## useGSheetWrite

The `useGSheetWrite` composable handles modifying sheet cells. It supports writing data in `appscript` or `service-account` authentication modes.

### Methods

*   `append(range, values)`: Appends rows to the sheet.
*   `update(range, values)`: Overwrites cells in a specific range.
*   `clear(range)`: Empties cell values in a range.

### Example

Add a new student record to your spreadsheet:

```vue [app.vue]
<script setup lang="ts">
const { append, pending } = useGSheetWrite({ sheet: 'siswa' })

const saveStudent = async () => {
  await append('A1:C1', [
    ['10023', 'John Doe', 'Kelas 10']
  ])
}
</script>

<template>
  <button :disabled="pending" @click="saveStudent">
    Add Student
  </button>
</template>
```
