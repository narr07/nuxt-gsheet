# Referensi Composables

Modul `nuxt-gsheet` menyediakan empat composables client-side yang di-auto-import secara otomatis untuk mengambil, mengubah, dan memperbarui data Google Sheets.

## useGSheet

Composable `useGSheet` adalah hook dasar. Fungsi ini mengambil data spreadsheet sebagai grid nilai mentah (array dari array).

### Parameter

*   `range` (string): Rentang sel yang akan diambil (contoh: `'Class Data!A1:F10'`).
*   `options` (object): Opsi opsional seperti `sheet`, `cacheMaxAge`, atau `valueRenderOption`.

### Contoh

Mengambil data grid mentah di dalam component SFC Anda:

```vue [app.vue]
<script setup lang="ts">
// Mengambil grid sel. Mengembalikan { data, pending, error, refresh }
const { data: grid, pending, error } = await useGSheet('Class Data!A1:F10')
</script>

<template>
  <div v-if="grid">
    <div v-for="(row, idx) in grid" :key="idx" class="flex gap-2">
      <span v-for="(cell, cellIdx) in row" :key="cellIdx">
        {{ cell }}
      </span>
    </div>
  </div>
</template>
```

## useGSheetAsObject

Composable `useGSheetAsObject` mengambil sel dan mengubah baris data menjadi array of objects. Fungsi ini memperlakukan baris pertama dari rentang sel sebagai kunci (header kolom).

### Contoh

Mengambil data siswa yang dipetakan ke header kolom:

```vue [app.vue]
<script setup lang="ts">
// Otomatis memetakan nilai sel ke kunci objek (header)
const { data: daftarSiswa } = await useGSheetAsObject('A1:C10', { sheet: 'siswa' })
</script>

<template>
  <ul v-if="daftarSiswa">
    <li v-for="siswa in daftarSiswa" :key="siswa.nis">
      {{ siswa.nama }} - {{ siswa.kelas }}
    </li>
  </ul>
</template>
```

## useGSheetRow

Composable `useGSheetRow` mengekstrak dan mengembalikan satu baris tertentu dari rentang sel berdasarkan posisi indeksnya (dimulai dari `0`).

### Contoh

Mengambil baris header (indeks `0`) dari spreadsheet:

```vue [app.vue]
<script setup lang="ts">
// Mengekstrak baris ke-0 (header)
const { data: headers } = await useGSheetRow('Class Data!A1:F10', 0)
</script>

<template>
  <div v-if="headers" class="flex gap-2">
    <span v-for="header in headers" :key="header" class="badge">
      {{ header }}
    </span>
  </div>
</template>
```

## useGSheetWrite

Composable `useGSheetWrite` menangani proses modifikasi sel spreadsheet. Fungsi ini mendukung penulisan data dalam mode autentikasi `appscript` atau `service-account`.

### Metode

*   `append(range, values)`: Menambahkan baris baru di bawah data yang ada.
*   `update(range, values)`: Menimpa sel pada rentang tertentu.
*   `clear(range)`: Mengosongkan nilai sel pada rentang tertentu.

### Contoh

Menambahkan data siswa baru ke spreadsheet Anda:

```vue [app.vue]
<script setup lang="ts">
const { append, pending } = useGSheetWrite({ sheet: 'siswa' })

const simpanSiswa = async () => {
  await append('A1:C1', [
    ['10023', 'John Doe', 'Kelas 10']
  ])
}
</script>

<template>
  <button :disabled="pending" @click="simpanSiswa">
    Tambah Siswa
  </button>
</template>
```
