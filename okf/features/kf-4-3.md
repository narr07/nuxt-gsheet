# KF 4.3 — SSR + SSG Support

Ensures data is fetched during server-side renders or build-time prerendering.

## Examples

```ts
// SSR: data is fetched on server during request
const { data } = await useGSheet('Sheet1!A:D')

// SSG / prerender: data is fetched at build time
// nuxt.config.ts
export default defineNuxtConfig({
  routeRules: {
    '/products': { prerender: true }
  }
})
```
