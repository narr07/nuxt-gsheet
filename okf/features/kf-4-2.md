# KF 4.2 — Nitro Server Plugin

A Server Plugin inside Nitro context (`runtime/server/plugins/gsheet.ts`) initializes and retains the authenticated client instance.

## Optimization
- Connections are pooled to prevent re-initializing authentication headers for every request.
- Edge support fallback uses native `fetch` over SDK native libraries where possible.
