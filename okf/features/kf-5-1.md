# KF 5.1 — Built-in response caching

Built-in response caching managed inside the module configurations.

## Configuration Example

```ts
gsheet: {
  cache: {
    enabled: true,
    maxAge: 300,     // 5 minutes default
    storage: 'memory' // or 'redis', 'fs' (supported via unstorage)
  }
}
```
