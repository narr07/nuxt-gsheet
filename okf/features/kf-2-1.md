# KF 2.1 — Mode: API Key (Public Sheets)

Allows read-only access to sheets shared publicly with "Anyone with the link can view".

## Configuration Example

```ts
gsheet: {
  auth: 'apikey',
  apiKey: process.env.GSHEET_API_KEY,
}
```

- Safe for public reading (via server proxy)
- No write operations allowed
