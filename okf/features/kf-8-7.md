# KF 8.7 — Deploy ke Cloudflare Pages

Configuration settings to build and publish static HTML exports to Cloudflare Pages.

## `docs/wrangler.toml` (Optional)
```toml
name = "nuxt-gsheet-docs"
compatibility_date = "2024-01-01"
pages_build_output_dir = ".output/public"
```

## Cloudflare Build Configurations
- **Build command**: `npm run generate` (produces static pre-rendered routes under `.output/public`)
- **Output directory**: `docs/.output/public`
- **Node version**: `22.x`
- **Root directory**: `docs`
