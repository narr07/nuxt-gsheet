# KF 6.3 — Informative error handling

Informative errors returned in the `error` ref of composables.

## Error Codes
- `QUOTA_EXCEEDED`: API quota limit has been reached.
- `NOT_FOUND`: Sheet or range is missing or inaccessible.
- `UNAUTHORIZED`: Credentials are missing or invalid.
- `NETWORK_ERROR`: Connection problems.
