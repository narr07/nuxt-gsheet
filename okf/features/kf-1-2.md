# KF 1.2 — Centralized configuration in `nuxt.config.ts`

Centralized module configuration in `nuxt.config.ts` using the `gsheet` key.

## Examples

```ts
export default defineNuxtConfig({
  modules: ['nuxt-gsheet'],
  gsheet: {
    apiKey: process.env.GSHEET_API_KEY,
    spreadsheetId: 'your-spreadsheet-id',
    // or multi-sheet
    sheets: {
      products: 'spreadsheet-id-1',
      users: 'spreadsheet-id-2',
    }
  }
})
```
