# KF 6.1 — TypeScript generics

Ensures correct typings are applied to output datasets using TypeScript generic variables.

## Examples

```ts
interface Product {
  id: string
  name: string
  price: number
}

const { data } = await useGSheet<Product[]>('Sheet1!A:D', {
  transform: (rows) => rows.map(([id, name, price]) => ({
    id, name, price: Number(price)
  }))
})
// 'data.value' is typed as Product[]
```
