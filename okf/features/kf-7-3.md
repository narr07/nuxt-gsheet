# KF 7.3 — Mode: CSV Export (Simplest)

Simplest fallback for read-only datasets, utilizing raw CSV exports from Google.

## Configuration Example
```ts
gsheet: {
  auth: 'csv',
  spreadsheetId: process.env.GSHEET_SPREADSHEET_ID,
  sheets: {
    products: '0',        // gid=0 for Sheet1
    users: '123456789',   // gid from the sheet URL
  }
}
```

## Internal Workflow
1. Proxies request to the Google export endpoint:
   `https://docs.google.com/spreadsheets/d/{spreadsheetId}/export?format=csv&gid={gid}`
2. Automatically parses the raw CSV string into an array of objects.
