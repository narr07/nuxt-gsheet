# KF 4.4 — Edge Runtime compat

Compatible with Cloudflare Workers, Vercel Edge, etc.

## Details
- Autodetects the runtime environment.
- Node.js runtime leverages the official `googleapis` SDK.
- Edge/Workers runtime falls back to raw `fetch` calls to `https://sheets.googleapis.com/v4/` since standard Node.js GCP SDK elements are incompatible.
