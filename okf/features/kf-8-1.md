# KF 8.1 — Setup Awal dari Nuxt UI Docs Template

Initialize the documentation site.

## Setup Instructions

```bash
# Clone template ke folder docs
npx nuxi init docs --template github:nuxt-ui-templates/docs
cd docs
npm install
```

{
  "name": "nuxt-gsheet-docs",
