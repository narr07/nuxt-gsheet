# KF 3.4 — `useGSheetWrite(options?)`

Provides write operations to Google Sheets. Requires service account or Apps Script write authentication.

## Examples

```ts
const { append, update, clear } = useGSheetWrite({ sheet: 'users' })
await append('Sheet1!A:D', [['4', 'Ani', 'ani@example.com']])
await update('Sheet1!B2', [['Updated Name']])
```
