# KF 1.1 — Zero-config auto-import composables

The Nuxt module will register the key composables so they are globally available without manual `import` statements.

## Specifications
- `useGSheet()` is registered for fetching values.
- `useGSheetRow()` is registered for single row fetching.
- `useGSheetRange()` (and other variants) are auto-imported in all `.vue` and `.ts` files inside Nuxt context.
