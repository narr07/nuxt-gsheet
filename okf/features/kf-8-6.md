# KF 8.6 — Navigation Config per Locale

Dynamic directory structures map automatically to sidebars utilizing Nuxt Content v3.

## Overriding labels
To override default sidebar labels, include `navigation` structures in the frontmatter:

### English frontmatter (`docs/content/en/...`)
```md
---
title: Installation
navigation:
  title: Installation
---
```

### Indonesian frontmatter (`docs/content/id/...`)
```md
---
title: Instalasi
navigation:
  title: Instalasi
---
```
