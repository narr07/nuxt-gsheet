# KF 1.3 — Support environment variables

Secure credential storage using environment variables.

## Supported Environment Variables
- `GSHEET_API_KEY`: API Key for public sheets reading.
- `GSHEET_CLIENT_EMAIL`: Service account client email.
- `GSHEET_PRIVATE_KEY`: Service account private key.
- `GSHEET_SPREADSHEET_ID`: Target Google Spreadsheet ID.
- `GSHEET_APPSCRIPT_URL`: Apps Script Web App URL for public reading/writing.
