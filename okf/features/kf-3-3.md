# KF 3.3 — `useGSheetAsObject(range, options?)`

Auto-converts sheets data layout where row 1 is the header row into an array of objects.

## Examples

```ts
// Auto-convert first row as header → array of objects
const { data } = await useGSheetAsObject('Sheet1!A:D')
// Result: [{ id: '1', name: 'Budi', email: 'budi@...' }]
```
