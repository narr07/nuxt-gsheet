# KF 2.3 — Mode: OAuth2 (User Context)

Optional authentication mode used when requests need to run under the user's specific context.

## Workflow
- User is redirected to `/api/gsheet/auth` to authenticate.
- Module retrieves OAuth tokens and proxies requests using the user's access token.
