# KF 3.2 — `useGSheetRow(range, rowIndex, options?)`

Composable targeting a specific row index.

## Examples

```ts
// Fetch a specific row (e.g. header row)
const { data } = await useGSheetRow('Sheet1!A:D', 0)
```
