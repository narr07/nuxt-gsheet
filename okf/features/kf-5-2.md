# KF 5.2 — Per-request cache override

Provides options to bypass global caching configurations on a per-request basis.

## Examples

```ts
const { data } = await useGSheet('Sheet1!A:D', {
  cache: false,           // bypass cache once
  cacheMaxAge: 10,        // override global max age (in seconds)
})
```
