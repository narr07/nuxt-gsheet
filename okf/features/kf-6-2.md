# KF 6.2 — Nuxt DevTools integration

Provides a custom tab within the Nuxt DevTools interface.

## Visualized Metrics
- Current sheet configuration details.
- Total HTTP request counters.
- Cache hit/miss states.
- Current API quota usage estimates.
