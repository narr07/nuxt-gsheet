# KF 2.2 — Mode: Service Account (Private Sheets)

Allows read and write access to sheets shared explicitly with the Service Account email.

## Configuration Example

```ts
gsheet: {
  auth: 'service-account',
  credentials: {
    clientEmail: process.env.GSHEET_CLIENT_EMAIL,
    privateKey: process.env.GSHEET_PRIVATE_KEY,
  }
}
```

- Support both read and write operations
- Best for private spreadsheets and admin-level tools
