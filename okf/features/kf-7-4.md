# KF 7.4 — Auto-detect Mode

The module automatically resolves the authentication mode from provided configs:

## Resolution Order
1. If `appscriptUrl` is defined → mode matches `appscript`.
2. If `apiKey` is defined → mode matches `apikey`.
3. If `credentials` (clientEmail and privateKey) are defined → mode matches `service-account`.
4. If only `spreadsheetId` is defined (without apiKey) → mode matches `gviz`.
